# แม่น้ำหวานลูก 4 🐱

เว็บโชว์รูมสินค้า Shopee affiliate ภาษาไทย ธีมแมว โทนครีม–ส้ม พร้อมภาพแม่แมวและลูกทั้งสี่ ใช้บนมือถือได้ หน้าแรกมีหัวเว็บครอบครัวแมว ช่องค้นหา หมวดหมู่ภาพเรียงแนวนอน และสินค้าแบบตาราง (3 คอลัมน์ตามภาพอ้างอิงบนจอใหญ่และมือถือ) กดหมวดเพื่อกรองสินค้า ค้นหา และเรียงราคาต่ำไปสูงหรือสูงไปต่ำ ค่าเริ่มต้นให้สินค้าที่แอดมินเลือก “น้ำหวานแนะนำ” ขึ้นก่อน แล้วใช้ลำดับแสดงผลที่ตั้งไว้ ปุ่ม “ดูใน Shopee” เปิดลิงก์ Shopee โดยตรง ปุ่มหัวใจบันทึกสินค้าในอุปกรณ์นี้และซิงก์ระหว่างแท็บ คำแนะนำสั้นใช้ข้อความที่แอดมินกรอกในช่องทำไมถึงแนะนำ ราคาและรายละเอียดเต็มกดเปิดผ่าน “อ่านเพิ่มเติม” บนการ์ดได้ มีหน้าจัดการสินค้า หมวดหมู่ และข้อมูลหน้าร้านที่ `/admin`

## การเผยแพร่เว็บที่เชื่อมแล้ว

- เว็บจริง: https://numwan.netlify.app/
- หลังบ้าน: https://numwan.netlify.app/admin
- Repository: https://github.com/Nitinainon/Namwan
- Production branch: `codex/namwan-showroom`
- Netlify build: `npm run build` → `dist`
- ตั้งค่า Supabase URL และ publishable key บน Netlify แล้ว

เมื่อ push โค้ดไปสาขานี้ GitHub webhook จะให้ Netlify build และเผยแพร่เว็บอัตโนมัติ ไม่ต้องอัปโหลด ZIP การแก้สินค้าและหมวดหมู่ผ่านแอดมินบันทึกลง Supabase โดยตรง

## เริ่มในเครื่อง

ใช้ Node.js 22.20 ขึ้นไป

```sh
npm install
cp .env.example .env.local
npm run dev
```

บน Windows คัดลอก `.env.example` เป็น `.env.local` ผ่าน File Explorer หรือ `Copy-Item .env.example .env.local` แล้วใส่ publishable key ของโปรเจกต์ ส่วน URL ตั้งไว้เป็นโปรเจกต์ของคุณแล้ว

```env
VITE_SUPABASE_URL=https://pmqdgnsypfubuwaebefx.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=คีย์ชนิด_publishable_ของโปรเจกต์
```

ไฟล์ `.env.local` ไม่ถูกส่งขึ้น Git หากไม่มี config เว็บจะมีตัวอย่างที่ระบุว่าเป็นตัวอย่างและไม่อนุญาตบันทึกสินค้า ถ้ามี config แต่ตารางยังไม่ติดตั้ง เว็บจะแจ้งว่าเปิดคอลเลกชันไม่ได้ และมีปุ่มดูตัวอย่างหน้าร้าน สินค้าตัวอย่างไม่ใช่สินค้าจริงหรือลิงก์ affiliate ของเจ้าของ

## ตั้ง Supabase และบัญชีแอดมิน

ทำตาม [คู่มือติดตั้ง Supabase](docs/setup-supabase.md) ก่อนใช้งานจริง ใช้ SQL migration ใน `supabase/migrations/202610070001_catalog.sql` สร้างตาราง ฟังก์ชันบันทึกข้อมูล สิทธิ์ RLS และ bucket รูป

หน้าร้านไม่มีลิงก์ไปหลังบ้าน แอดมินเปิด `<โดเมนเว็บ>/admin` โดยตรงและเข้าสู่ระบบด้วยยูเซอร์และรหัสผ่าน โดยใช้ Supabase Auth เบื้องหลัง เฉพาะผู้ที่ถูกเพิ่มใน `private.admin_users` จึงจัดการข้อมูลได้ ไม่ได้ให้สิทธิ์แอดมินกับทุกคนที่เข้าสู่ระบบ ดูวิธีตั้งยูเซอร์ `namwan` ในคู่มือติดตั้ง

## เปิดเว็บบน Netlify

1. ส่ง source code ไป repository `Nitinainon/Namwan` และเลือก branch ที่มีเว็บ
2. ใน Netlify เลือก Add new project → Import an existing project → GitHub → repository `Namwan`
3. Build command: `npm run build` และ Publish directory: `dist` (มี `netlify.toml` ตั้งไว้ให้)
4. ตั้ง environment variables `VITE_SUPABASE_URL` และ `VITE_SUPABASE_PUBLISHABLE_KEY` สำหรับบริบทที่จะ deploy แล้ว deploy ใหม่
5. ตั้ง Site URL และ redirect URLs ของ Supabase Auth ให้ตรง URL Netlify ของคุณ
6. เปิดหน้าร้านและ `/admin` ทดสอบบัญชีแอดมิน เพิ่มหมวดหมู่และสินค้าแรก แล้วเปิดหน้าร้านจากอีกอุปกรณ์เพื่อตรวจข้อมูล

การเปลี่ยนสินค้าและหมวดหมู่ทำผ่านแอดมินได้ทันที ไม่ต้อง deploy ทุกครั้ง ข้อมูลอยู่ใน Supabase และไม่หายเพราะ deploy เว็บใหม่

อีกทางเลือกคือ build แล้วอัปโหลดโฟลเดอร์ `dist` ผ่าน Netlify Drop ไฟล์ `_redirects` และ `_headers` ใน build รองรับ `/admin` และ headers สำหรับการอัปโหลดแบบนี้ด้วย ไฟล์ `release/namwan-netlify.zip` ที่ส่งมอบเป็น build ของโปรเจกต์ Supabase ที่คุณให้มา ต้องติดตั้งฐานข้อมูลและบัญชีแอดมินก่อนจัดการสินค้าได้

## ใช้หน้าแอดมิน

- **สินค้า:** เพิ่มชื่อ รูป ราคาโดยประมาณ เหตุผลที่แนะนำ และลิงก์ affiliate ที่คุณสร้างจากบัญชี Shopee เอง เลือกหมวดหมู่และลำดับ (ตัวเลขน้อยแสดงก่อน) เปิด “เผยแพร่ในหน้าร้าน” เพื่อให้ลูกค้าเห็น หรือปิดเพื่อเก็บฉบับร่าง
- **รูป:** อัปโหลด JPG/PNG/WebP ไม่เกิน 5 MB หรือใช้ URL HTTPS รูปใน bucket เป็นสาธารณะ แม้สินค้าเป็นฉบับร่าง ไม่ใช้เก็บข้อมูลส่วนตัว
- **น้ำหวานแนะนำ:** เปิดตัวเลือกนี้เพื่อให้สินค้าติดป้ายและค้นด้วยตัวกรองสินค้าแนะนำ
- **หมวดหมู่:** เพิ่ม เปลี่ยนชื่อ และลำดับ ก่อนลบหมวดต้องย้ายสินค้าที่อยู่ในหมวดนั้นไปหมวดอื่นหรือเลือก “ยังไม่จัดหมวดหมู่”
- **ข้อมูลหน้าร้าน:** แก้ชื่อเว็บ คำโปรย ข้อความแนะนำ รูปแบนเนอร์ และข้อความแจ้ง affiliate ปล่อยแบนเนอร์ว่างเพื่อใช้ภาพแมวเดิม
- **รหัสผ่าน:** เปลี่ยนผ่านเมนูข้อมูลหน้าร้าน ต้องอย่างน้อย 12 ตัวอักษร
- **ข้อมูลเปลี่ยนจากอีกหน้าต่าง:** คัดลอกข้อความที่แก้ไขไว้ ปิดฟอร์ม กดโหลดข้อมูลล่าสุด แล้วเปิดแก้ไขใหม่ ระบบไม่เขียนทับข้อมูลใหม่โดยอัตโนมัติ

ไม่มีการดึงสินค้าหรือราคา Shopee อัตโนมัติ และไม่มีชำระเงินในเว็บ เมื่อผู้ชมกดปุ่มซื้อจะไปยัง URL ที่แอดมินบันทึกไว้โดยคง tracking ของลิงก์

## ตรวจสอบ

```sh
npm test
npm run build
npm audit
```

ชุดทดสอบฐานข้อมูลรัน migration จริงใน PostgreSQL ผ่าน PGlite และจำลอง schema Auth/Storage เฉพาะส่วนที่ใช้ ตรวจ RLS ผู้เข้าชม/ผู้ใช้ทั่วไป/แอดมิน การถอนสิทธิ์ หมวดหมู่ที่ยังมีสินค้า และ revision conflict ส่วนการเข้าสู่ระบบ อัปโหลดจริง และการเข้าถึงจากอีกอุปกรณ์ต้องตรวจเพิ่มเติมบน Supabase ที่ติดตั้งแล้ว

SQL smoke test สำหรับ Supabase SQL Editor อยู่ใน `supabase/tests/authorization.sql` และ rollback ข้อมูลทดสอบหลังจบ

## การเก็บรูปและ session

การลบสินค้าไม่ลบรูปจาก Storage อัตโนมัติ เพราะรูปเดียวอาจถูกใช้หลายสินค้า รูปที่อัปโหลดแล้วไม่ได้บันทึกอาจค้างอยู่ใน bucket ให้ผู้ดูแลตรวจและลบรูปที่ไม่ใช้ผ่าน Supabase Dashboard

ออกจากระบบจะล้าง session ในแอป แต่ JWT ที่ถูกออกไปแล้วมีอายุจนหมดเวลาที่กำหนด การถอนชื่อจาก `private.admin_users` จะปฏิเสธการเขียนด้วย RLS ทันที ไม่ใส่ service_role/secret key ในหน้าเว็บ
