# แบบระบบเว็บโชว์รูมสินค้า Namwan

วันที่: 7 ตุลาคม 2026
สถานะ: เสนอให้ผู้ใช้ตรวจแบบก่อนจัดทำแผนพัฒนา

## เป้าหมายและขอบเขต

สร้างเว็บภาษาไทยสำหรับรวบรวมสินค้า Shopee ที่เจ้าของแนะนำ ผู้เข้าชมค้นหาและเลือกหมวดหมู่สินค้า แล้วกดลิงก์ affiliate ที่เจ้าของใส่ไว้เพื่อไปซื้อบน Shopee รองรับมือถือเป็นหลักและจอคอมพิวเตอร์ โฮสต์บน Netlify และเก็บ source code ใน repository Nitinainon/Namwan

ผู้ใช้ระบุว่าการแก้ไขข้อมูลเบื้องหลังทั้งหมดต้องทำผ่านลิงก์แอดมินและต้องมีรหัสผ่าน สมมติฐานสำหรับรุ่นแรกคือเจ้าของเป็นผู้ดูแลคนเดียว ชื่อ “น้ำหวานคัดให้” เป็นค่าเริ่มต้นที่แก้ได้ในหน้าจัดการ

## หน้าร้านและภาพลักษณ์

ธีมครีม ชมพูพาสเทล และน้ำตาลอ่อน มีภาพแมวประกอบและมุมโค้ง ใช้ตัวอักษรไทยอ่านง่าย ปุ่มเหมาะกับการกดบนมือถือ รองรับแป้นพิมพ์และมีข้อความกำกับฟอร์ม

หน้าร้านประกอบด้วยชื่อเว็บ คำโปรย ช่องค้นหา ตัวกรองหมวดหมู่ สินค้าแนะนำ และรายการสินค้า การ์ดแสดงรูป ชื่อ ราคาโดยประมาณ และเหตุผลที่แนะนำ มีรายละเอียดสินค้าและปุ่มเปิด Shopee ในแท็บใหม่ คงลิงก์ affiliate ที่เจ้าของบันทึกไว้ พร้อมข้อความแจ้งว่าลิงก์บางรายการเป็น affiliate และราคาอาจเปลี่ยนแปลง

ไม่มีการชำระเงินบนเว็บ ไม่มีการสร้างลิงก์ affiliate หรือดึงราคา Shopee อัตโนมัติ เจ้าของกรอกข้อมูลและนำลิงก์ affiliate ของตนเองมาใส่

## ระบบแอดมิน

เข้าทาง /admin แสดงหน้าเข้าสู่ระบบเมื่อยังไม่ได้ยืนยันตัวตน เจ้าของกรอกรหัสผ่านที่ตั้งผ่าน environment variable ของ Netlify รหัสผ่านและข้อมูลลับจะไม่ส่งให้หน้าร้าน ไม่ใส่ไว้ใน source code หรือ browser storage

หลังเข้าสู่ระบบ จัดการได้ดังนี้:

- สินค้า: เพิ่ม แก้ไข ลบ อัปโหลดหรือเปลี่ยนรูป กรอกชื่อ คำอธิบาย ราคา เหตุผลที่แนะนำ ลิงก์ affiliate หมวดหมู่ สถานะแนะนำ ลำดับ และสถานะเผยแพร่
- หมวดหมู่: เพิ่ม เปลี่ยนชื่อ เรียงลำดับ และลบ โดยต้องย้ายสินค้าที่ใช้หมวดนั้นก่อนลบ
- ข้อมูลหน้าร้าน: ชื่อเว็บ คำโปรย ข้อความแนะนำ แบนเนอร์ และข้อความ affiliate

ฟอร์มมีสถานะกำลังบันทึก ผลสำเร็จ และข้อผิดพลาด เมื่อบันทึกล้มเหลวคงข้อมูลที่กรอกไว้ ยืนยันก่อนลบ และป้องกันการกดบันทึกซ้ำ มีปุ่มออกจากระบบ การเปลี่ยนรหัสผ่านทำผ่านการตั้งค่า Netlify สำหรับรุ่นแรก

## โครงสร้างและการเก็บข้อมูล

ใช้ React, TypeScript และ Vite สำหรับหน้าเว็บ ใช้ Netlify Functions เป็น API และ Netlify Blobs แบบ site-wide สำหรับข้อมูลและรูปเพื่อคงข้อมูลเมื่อ deploy ใหม่ แยกข้อมูลสินค้า หมวดหมู่ ข้อมูลหน้าร้าน และ sessions ออกจากกัน

หน้าร้านอ่านเฉพาะสินค้าที่เผยแพร่ ส่วน API จัดการข้อมูลทั้งหมดตรวจ session ฝั่งเซิร์ฟเวอร์ทุกครั้ง session ใช้ token แบบสุ่ม เก็บใน cookie HttpOnly, Secure และ SameSite พร้อมวันหมดอายุและเพิกถอนเมื่อออกจากระบบ ตรวจ origin สำหรับการแก้ไขข้อมูลและจำกัดการลองรหัสผ่าน รหัสผ่านตั้งใน environment ของ production; development ใช้ค่าทดสอบแยกต่างหาก

ตรวจชนิดและขนาดรูปก่อนบันทึก รับ JPEG, PNG และ WebP ตรวจ URL ให้เป็น HTTPS และลิงก์ Shopee ของประเทศไทยหรือโดเมน short link ที่รองรับ ไม่แสดง HTML ที่ผู้ดูแลกรอกเป็น HTML จริง

ข้อมูลมี ID ถาวรและ revision ตรวจ revision ก่อนบันทึกเพื่อแจ้งเมื่อข้อมูลเปลี่ยนจากอีกแท็บ การปรับข้อมูลหมวดหมู่และการลบต้องตรวจความสัมพันธ์กับสินค้า เก็บรูปผ่าน API ที่ควบคุมสิทธิ์อัปโหลดและอนุญาตอ่านรูปสาธารณะตามการใช้งานหน้าร้าน

## การเชื่อมต่อและเผยแพร่

จัดเตรียม netlify.toml สำหรับ build, routing และ Functions พร้อมคู่มือภาษาไทยสำหรับเชื่อม GitHub กับ Netlify ตั้งค่ารหัสผ่านและ secret และเข้าหน้า /admin การเผยแพร่จริงขึ้นอยู่กับสิทธิ์บัญชี GitHub และ Netlify ที่เข้าถึงได้ ต้องรายงาน URL จริงหลัง deploy สำเร็จเท่านั้น

เริ่มด้วยข้อมูลตัวอย่างที่ระบุว่าเป็นตัวอย่าง ไม่มีการอ้างว่าเป็นลิงก์ affiliate จริงของเจ้าของ เจ้าของสามารถลบหรือแทนที่ข้อมูลตัวอย่างทั้งหมดผ่านหน้าแอดมิน

## เกณฑ์ตรวจรับ

- หน้าร้านใช้งานได้บนมือถือโดยไม่มีการเลื่อนแนวนอน และค้นหา/กรองหมวดหมู่ได้
- เมื่อยังไม่เข้าสู่ระบบ ไม่สามารถเพิ่ม แก้ไข ลบ หรืออัปโหลดผ่าน API ได้ แม้เรียก API โดยตรง
- รหัสผ่านผิดเข้าสู่ระบบไม่ได้ ออกจากระบบแล้ว session เดิมใช้แก้ไขข้อมูลไม่ได้
- เพิ่ม แก้ไข ลบสินค้าและจัดการหมวดหมู่ผ่าน /admin ได้ และเปิดจากอีกอุปกรณ์เห็นข้อมูลที่บันทึก
- ข้อมูลคงอยู่หลัง deploy ใหม่ และข้อผิดพลาดการบันทึกไม่ทำให้ข้อมูลเดิมหาย
- ข้อมูลหน้าร้านที่แก้ไขจาก /admin แสดงในหน้าร้าน และลิงก์สินค้าเปิด URL ที่บันทึกไว้
- build ผ่าน ตรวจเส้นทางหลักและสิทธิ์ API รวมถึงพฤติกรรมเมื่อ backend ใช้งานไม่ได้
